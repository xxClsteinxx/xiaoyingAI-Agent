# 04 AI 使用声明

## 使用范围

本仓库初稿由 OpenAI Codex 在候选人提供完整题目后辅助生成，覆盖：需求拆分、目录和代码初稿、测试用例、合成数据、说明文档以及验证命令。Codex 还检索了官方 OpenAI Responses API 文档以核对真实模型适配层，并在本地运行测试、根据失败结果修复示例生成脚本。

AI 未执行：使用真实业务数据、调用真实发布接口、使用候选人的模型密钥、创建或推送 GitHub 仓库、替候选人确认个人经历。

## 人工贡献与提交前责任

候选人贡献目前可确认的只有：提供考核原题并决定采用第 1 题。其余个人修改、理解说明和实际投入时间，必须由候选人在提交前据实补充；不应把 AI 生成内容冒充个人独立完成。

建议候选人提交前完成并记录：

1. 逐文件代码审阅，能解释动态决策与护栏边界；
2. 亲自运行 README 的命令并核对输出；
3. 至少完成一次有意义的个人修改，并在本节写清修改原因；
4. 如有 API key，补跑真实模型用例并保存独立证据；没有则保留当前明确边界；
5. 填写实际总用时和未完成项。

## 验证记录

AI 辅助产物已通过标准库 `unittest` 自动测试；结果位于 `examples/test-results.txt`。当前验证不能替代候选人最终复核，也不能证明真实模型效果。
